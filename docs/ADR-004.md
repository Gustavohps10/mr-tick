# ADR-004 — Sistema de Addons Multicapacidade desacoplado via SDK (@mr-tick/sdk)

## Status

**Aceito** (Substitui proposta inicial de módulos PRO proprietários; Core consolidado 100% gratuito e open-source sob licença Apache 2.0)

## Data

24 de Agosto de 2026 (Atualizado em Outubro de 2026)

## Autor

Gustavo Henrique Pereira dos Santos

---

## 1. Contexto

O **Mr. Tick** é uma plataforma Local-First com foco em produtividade para desenvolvedores e equipes de engenharia. Em vez de acoplar provedores externos (como Redmine, Jira, GitLab) diretamente ao código do aplicativo desktop ou fragmentar a extensão em múltiplos tipos incompatíveis de plugins, o sistema necessita de uma camada unificada de extensibilidade.

### 1.1 Premissas Fundamentais

1. **Core Livre e Expansível:** O core do software é distribuído sob licença permissiva **Apache 2.0**, gratuito e sem paywalls ou travas no executável principal.
2. **Desacoplamento Rigoroso:** O Core e a UI do Mr. Tick não conhecem implementações específicas de provedores de dados ou ferramentas de terceiros.
3. **Privacidade Absoluta (Zero-Cloud Data Policy):** Toda e qualquer integração executa localmente. As credenciais e requisições HTTP trafegam exclusivamente da máquina do usuário para o servidor corporativo integrado.

---

## 2. Decisão

Adota-se a arquitetura de **Addons Multicapacidade** orientada pelo pacote `@mr-tick/sdk`.

Um único Addon (pacote npm ou módulo local) pode registrar uma ou mais capacidades através de um manifesto e contrato estruturado:

1. **DataSources (`capacity: 'datasource'`):**
   - Fornece conectores para busca de tarefas, projetos, atividades e sincronização bidirecional de apontamentos de tempo.
   - Comunicação funcional e tipada via padrão `Either<Failure, Success>`.
2. **Watchers (`capacity: 'watcher'`):**
   - Monitoramento passivo e observabilidade local (detecção de janelas ativas, branches Git locais, idle time).
3. **Temas & Estilos (`capacity: 'theme'`):**
   - Injeção dinâmica de variáveis de estilo CSS (compatíveis com Tailwind v4 / Shadcn) em tempo de execução.
4. **Menus & Atalhos (`capacity: 'menu'`):**
   - Extensão da barra superior (Timerbar), Sidebar e atalhos rápidos de navegação.

### 2.1 Isolamento e Runtime

- Os addons são carregados em tempo de execução pelo `AddonLoader` em memória.
- Cada addon declara suas permissões e capacidades necessárias em seu `addon.manifest.json`.
- O Core provê aos addons o contexto do workspace ativo, APIs de storage local isolado e bridges seguros para emissão de eventos.

---

## 3. Consequências

- **Flexibilidade:** A comunidade e empresas podem criar integrações customizadas sem alterar uma única linha do repositório principal.
- **Segurança e Estabilidade:** Falhas em um conector externo não derrubam o timer ou o banco local RxDB do usuário.
- **Aderência aos Contratos Canônicos:** O SDK garante tipos estritos (`SyncTimeEntryDTO`, `Either`, etc.), mantendo a integridade da sincronização idempotente.
