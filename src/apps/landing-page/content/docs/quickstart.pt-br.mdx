Neste guia você vai criar um addon de tema pequeno, depois compilá-lo e gerar um pacote para instalar no Mr. Tick. É uma forma simples de conhecer a mesma estrutura de projeto usada pelas outras integrações. Comece em um projeto separado e instale o SDK publicado:

```bash
npm init -y
npm install @mr-tick/sdk@^0.10.0
npm install -D typescript tsup @types/node
```

Configure TypeScript com `strict: true`, `target: ES2022`, `module: ESNext` e `moduleResolution: bundler`; defina `type: module` no package.json. Crie manifest.yaml e src/index.ts:

```yaml
id: example-addon
name: Example Addon
version: 0.1.0
author: Example
shortDescription: SDK example
description: Example using the published SDK
capabilities:
  - theme
requiredApiVersion: '>=0.10.0'
```

```ts
import type { AddonContext, AddonTheme, IAddon } from '@mr-tick/sdk'

const theme: AddonTheme = {
  id: 'ocean',
  name: 'Ocean',
  css: ':root { --primary: oklch(0.6 0.15 240); } .dark { --primary: oklch(0.75 0.12 240); }',
}

export default class OceanAddon implements IAddon {
  activate(context: AddonContext): void {
    context.contributions.themes.register(theme)
  }

  deactivate(): void {}
}
```

Registre as funcionalidades em `activate` e retorne sem esperar que todos os serviços do aplicativo estejam prontos. Ao desativar o addon, o Mr. Tick remove os registros feitos por ele. Use `deactivate` para fechar conexões e encerrar tarefas que o próprio addon iniciou.

```bash
npx tsup src/index.ts --format esm,cjs --dts --clean
npx mr-tick validate .
npx mr-tick pack . --download-url https://example.com/releases/example-addon.tladdon
```

Instale o `.tladdon` resultante pelo gerenciador de addons; um JavaScript compilado avulso não é um pacote de instalação. A CLI deriva o intervalo de API do pacote da versão do SDK. Repositórios gerenciados por Changesets fazem releases via changesets e CI; não altere versões nem reescreva histórico manualmente.

Consulte [conexões](/pt-br/docs/apis/connections), [OAuth PKCE](/pt-br/docs/apis/oauth-pkce) e [cofre e eventos](/pt-br/docs/apis/vault-and-events).
