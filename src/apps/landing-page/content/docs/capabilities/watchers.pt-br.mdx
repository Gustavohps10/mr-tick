---
title: "Watchers e sugestões"
description: Observe atividades e transforme eventos em sugestões de apontamento.
icon: Activity
---

Declare `capabilities: [watcher]`. Observe eventos do provedor, sockets locais ou processos externos dentro do addon. Autentique pela API de contribuição de conexões; não registre datasource apenas para guardar credenciais.

```yaml
id: example-addon
name: Example Addon
version: 0.1.0
author: Example
shortDescription: SDK example
description: Example using the published SDK
capabilities:
  - watcher
requiredApiVersion: '>=0.10.0'
```

```ts
import type {
  AddonContext,
  LocalEntryInput,
  LocalOperationIdentity,
} from '@mr-tick/sdk'

export function suggest(
  context: AddonContext,
  workspaceId: string,
  input: LocalEntryInput,
  operation: LocalOperationIdentity,
) {
  return context.core.timeEntries.createSuggestion(
    workspaceId,
    input,
    operation,
  )
}
```

Escolha workspace, conexão de origem, tarefa e atividade explicitamente. `LocalEntryInput` usa segundos e datas ISO. Aloque IDs da operação antes da escrita e os reutilize somente em repetições com conteúdo idêntico. Sucesso significa sugestão local, não confirmação remota.

Eventos garantidos: `timer:start`, `timer:pause`, `timer:resume`, `timer:stop`, `timer:update`, `workspace:changed`. Nenhuma API de assinatura de idle é garantida. Registre listeners e retorne da ativação; feche recursos próprios na desativação. Trocas de workspace não desativam o addon.

Consulte [conexões](/pt-br/docs/apis/connections), [OAuth PKCE](/pt-br/docs/apis/oauth-pkce) e [cofre e eventos](/pt-br/docs/apis/vault-and-events).
