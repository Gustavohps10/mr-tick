Uma **capability** descreve uma funcionalidade oferecida pelo addon. O Mr. Tick lê essa informação para saber onde ele pode ser usado. Por exemplo, uma integração de tarefas usa `dataSource`, enquanto um tema visual usa `theme`.

Liste as funcionalidades em `capabilities`, no arquivo manifest.yaml. Os nomes aceitos são `auth`, `dataSource`, `watcher`, `calendar`, `punch` e `theme`; escreva-os exatamente assim. A lista precisa ter pelo menos um valor e não pode ter repetidos. Um addon pode oferecer mais de uma funcionalidade.

Use `requiredApiVersion` para informar a API compatível do aplicativo. Menus, comandos e configurações são registrados pelo código do addon. Para conectar contas externas, declare também `auth` e registre seus perfis e autenticadores durante a ativação.
