# Observers & Watchers de Atividade

Os **Watchers** (ou Observers) são plugins projetados para monitorar passivamente o fluxo de trabalho do usuário no computador — como presença em canais de voz, commits em repositórios Git, arquivos abertos em IDEs ou períodos de inatividade.

O objetivo de um Watcher é emitir **Sugestões Inteligentes de Apontamento** para que o usuário registre suas horas com apenas **1 clique**, sem digitação manual.

---

## 🎧 Casos de Uso Comuns

- **Monitor de Reuniões**: Detecta entrada e saída de chamadas de voz no Discord, Google Meet ou Slack e sugere o apontamento da reunião com a duração exata.
- **Detector de Inatividade (Idle)**: Escuta o evento `onIdleDetected` do Mr-tick e sugere pausar o cronômetro ou alocar o tempo ausente.
- **Monitor de Git / IDE**: Observa branches de desenvolvimento e sugere apontamentos vinculados aos tickets das branches trabalhadas no dia.

## 💻 Exemplo Prático de um Watcher

### 1. `manifest.yaml`
```yaml
id: reunioes-watcher
name: Watcher de Reuniões
version: 1.0.0
description: Detecta chamadas e sugere apontamentos de reuniões
author: Sua Empresa <contato@empresa.com>
main: dist/index.js
```

### 2. `src/index.ts`
```typescript
import type { IAddon, AddonContext } from '@mr-tick/sdk'

export default class ReunioesWatcherAddon implements IAddon {
  private context: AddonContext | null = null

  public activate(context: AddonContext): void {
    this.context = context

    // Registra as preferências de configuração no formato de abas/grupos
    context.settings.register([
      {
        id: 'general',
        label: 'Geral',
        groups: [
          {
            id: 'preferences',
            label: 'Preferências do Observador',
            fields: [
              {
                id: 'atividadePadrao',
                label: 'ID da Atividade de Reunião',
                type: 'text',
                description:
                  'Código da atividade padrão para reuniões no seu DataSource.',
              },
            ],
          },
        ],
      },
    ])

    // Escutando eventos do sistema nativo
    context.events.onSystemIdle?.((idleTimeSeconds) => {
      console.log(`[Watcher] Usuário inativo por ${idleTimeSeconds} segundos.`)
    })
  }

  public deactivate(): void {
    this.context = null
  }

  // Emite uma sugestão diretamente para a timeline de Time Entries
  public async emitirSugestaoDeApontamento(
    titulo: string,
    duracaoSegundos: number,
  ): Promise<void> {
    if (!this.context) return

    await this.context.timeEntries.createSuggestion({
      taskId: '',
      comments: `Reunião: ${titulo}`,
      timeSpentSeconds: duracaoSegundos,
      source: 'addon',
    })

    await this.context.notifications.success(
      `Sugestão gerada: ${Math.round(duracaoSegundos / 60)} min em "${titulo}"`,
      'Reuniões Watcher',
    )
  }
}
```

---

## ⚡ Como a Interface Processa as Sugestões

1. O Watcher identifica o término de uma atividade contextual e dispara uma notificação ou evento.
2. O Mr-tick exibe um **card de sugestão contextual** na tela de _Time Entries_.
3. O usuário pode clicar em **Aceitar** (salvando o apontamento imediatamente com os dados sugeridos) ou **Descartar**.
