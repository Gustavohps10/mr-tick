# Calendars (Agendas & Reuniões)

Os addons da categoria **Calendars** conectam o Mr-tick a provedores de agenda como **Google Calendar**, **Microsoft Outlook / 365** e calendários baseados em **iCal**.

Essa integração permite que os compromissos diários apareçam diretamente na visualização de agenda do Mr-tick, possibilitando que o usuário transforme reuniões passadas em apontamentos de horas reais com um simples clique.

---

## 🎯 Estrutura de um Evento de Calendário

Para alimentar a interface do Mr-tick, o plugin de calendário normaliza os eventos externos para uma estrutura padrão:

```typescript
export interface CalendarEventDTO {
  id: string // Identificador único do evento no provedor externo
  title: string // Título ou assunto da reunião
  description?: string // Pauta ou descrição do evento
  startDate: Date // Data e hora de início
  endDate: Date // Data e hora de término
  attendeesCount?: number // Quantidade de participantes
  meetLink?: string // Link da chamada (Google Meet, Teams, Zoom)
  isAllDay?: boolean // Indica se é um evento de dia inteiro
}
```

## 💻 Exemplo de Implementação de Calendário

### 1. `manifest.yaml`
```yaml
id: google-calendar-addon
name: Google Calendar Integration
version: 1.0.0
description: Sincroniza reuniões do Google Calendar com o Mr-tick
author: Sua Empresa <contato@empresa.com>
main: dist/index.js
```

### 2. `src/index.ts`
```typescript
import type { IAddon, AddonContext } from '@mr-tick/sdk'

export interface CalendarEventDTO {
  id: string
  title: string
  startDate: Date
  endDate: Date
  meetLink?: string
}

interface GoogleCalendarApiItem {
  id: string
  summary?: string
  start: { dateTime?: string; date?: string }
  end: { dateTime?: string; date?: string }
  hangoutLink?: string
}

interface GoogleCalendarApiResponse {
  items?: GoogleCalendarApiItem[]
}

export default class GoogleCalendarAddon implements IAddon {
  private context: AddonContext | null = null

  public activate(context: AddonContext): void {
    this.context = context

    context.settings.register([
      {
        id: 'general',
        label: 'Geral',
        groups: [
          {
            id: 'calendar_config',
            label: 'Configurações do Calendário',
            fields: [
              {
                id: 'calendarId',
                label: 'ID do Calendário',
                type: 'text',
                defaultValue: 'primary',
                description:
                  'Identificador do calendário (use "primary" para o principal).',
              },
            ],
          },
        ],
      },
    ])

    console.log('[GoogleCalendar] Addon ativado com sucesso!')
  }

  public deactivate(): void {
    this.context = null
  }

  // Busca os eventos do dia especificado
  public async fetchDayEvents(targetDate: Date): Promise<CalendarEventDTO[]> {
    const accessToken = await this.context?.storage.get('accessToken')
    if (!accessToken) {
      throw new Error('Usuário não autenticado no Google Calendar.')
    }

    const startOfDay = new Date(targetDate)
    startOfDay.setHours(0, 0, 0, 0)

    const endOfDay = new Date(targetDate)
    endOfDay.setHours(23, 59, 59, 999)

    const url = new URL(
      'https://www.googleapis.com/calendar/v3/calendars/primary/events',
    )
    url.searchParams.set('timeMin', startOfDay.toISOString())
    url.searchParams.set('timeMax', endOfDay.toISOString())
    url.searchParams.set('singleEvents', 'true')
    url.searchParams.set('orderBy', 'startTime')

    const response = await fetch(url.toString(), {
      headers: { Authorization: `Bearer ${accessToken}` },
    })

    const data: GoogleCalendarApiResponse = await response.json()

    return (data.items || []).map((item: GoogleCalendarApiItem): CalendarEventDTO => ({
      id: item.id,
      title: item.summary || 'Sem título',
      startDate: new Date(item.start.dateTime || item.start.date || targetDate),
      endDate: new Date(item.end.dateTime || item.end.date || targetDate),
      meetLink: item.hangoutLink,
    }))
  }
}
```

## 🚀 Conversão Rápida para Apontamento de Horas

Quando o usuário visualiza suas reuniões no Mr-tick:

1. O Mr-tick destaca reuniões já encerradas.
2. Com o botão **"Apontar Horas"**, o Mr-tick abre o formulário pré-preenchido com o título da reunião, as horas calculadas (`(endDate - startDate)`) e a atividade sugerida.
3. Ao salvar, a entidade `TimeEntry` é criada e enviada para o [Motor de Sincronização](/docs/sync-engine).
