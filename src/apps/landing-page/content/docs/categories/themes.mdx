# Themes (Temas & Customização Visual)

Os addons da categoria **Themes** permitem personalizar completamente a estética visual do Mr-tick — definindo paletas de cores para modos Claro (Light) e Escuro (Dark), contrastes, bordas e tipografia.

O Mr-tick adota o padrão de design system baseado em **Tokens CSS** (compatível com Tailwind CSS e shadcn/ui), tornando a criação de novos temas simples e declarativa.

---

## 🎨 Estrutura de um Tema

Um tema exporta a definição `AddonTheme` contendo o CSS completo (compatível com variáveis Tailwind CSS / shadcn/ui):

```typescript
export interface AddonTheme {
  id: string
  name: string
  description?: string
  css: string
}
```

---

## 💻 Exemplo de Implementação de Tema

### 1. `manifest.yaml`
```yaml
id: cyberpunk-theme
name: Cyberpunk Neon Theme
version: 1.0.0
description: Tema com estética cyberpunk e cores neon vibrantes
categories:
  - theme
author: Sua Empresa <contato@empresa.com>
```

### 2. `src/index.ts`
```typescript
import type {
  AddonActionResponse,
  AddonContext,
  AddonTheme,
  IAddon,
} from '@mr-tick/sdk'

export const CYBERPUNK_THEME: AddonTheme = {
  id: 'cyberpunk-theme',
  name: 'Cyberpunk Neon',
  description: 'Paleta neon com tons rosa e ciano vibrantes.',
  css: `
    :root {
      --background: 0 0% 100%;
      --foreground: 240 10% 3.9%;
      --primary: 326 100% 50%;
    }
    .dark {
      --background: 260 25% 8%;
      --foreground: 180 100% 95%;
      --primary: 180 100% 50%;
    }
  `,
}

export default class CyberpunkThemeAddon implements IAddon {
  private activeContext: AddonContext | null = null

  public activate(context: AddonContext): void {
    this.activeContext = context

    // 1. Registra o tema no sistema
    context.themes.register(CYBERPUNK_THEME)

    // 2. Registra a tela de configuração com botões de ação
    context.settings.register([
      {
        id: 'general',
        label: 'Geral',
        groups: [
          {
            id: 'theme_controls',
            label: 'Controles do Tema',
            fields: [
              {
                id: 'apply-theme',
                type: 'button',
                label: 'Ativar Tema Cyberpunk',
                actionId: 'apply-theme',
              },
              {
                id: 'reset-theme',
                type: 'button',
                label: 'Restaurar Tema Padrão',
                variant: 'destructive',
                actionId: 'reset-theme',
              },
            ],
          },
        ],
      },
    ])

    // 3. Registra os comandos das ações
    context.commands.register('apply-theme', async (): Promise<AddonActionResponse> => {
      await context.commands.execute('theme:set', CYBERPUNK_THEME.id)
      return {
        isSuccess: true,
        display: {
          title: 'Tema Cyberpunk Ativado!',
          message: 'Estilo visual aplicado com sucesso.',
        },
      }
    })

    context.commands.register('reset-theme', async (): Promise<AddonActionResponse> => {
      await context.commands.execute('theme:set', '')
      return {
        isSuccess: true,
        display: {
          title: 'Tema Padrão Restaurado!',
          message: 'Interface retornou ao padrão do Mr-tick.',
        },
      }
    })
  }

  public deactivate(): void {
    if (this.activeContext) {
      this.activeContext.themes.unregister(CYBERPUNK_THEME.id)
      this.activeContext = null
    }
  }
}
```

---

## ⚙️ Como o Mr-tick Aplica os Temas

1. Quando o usuário seleciona o tema nas preferências do Mr-tick, o Core injeta dinamicamente as variáveis CSS na raiz do DOM (`:root` ou classe `.dark`).
2. Todos os componentes da interface (Time Bar, Listas de Tarefas, Modais e Menus) atualizam suas cores instantaneamente sem necessidade de recarregar a janela.
