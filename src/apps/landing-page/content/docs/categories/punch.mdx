# Punch (Ponto Eletrônico & Jornada)

Os addons da categoria **Punch** integram o Mr-tick a sistemas formais de **Bate-Ponto e Controle de Ponto Eletrônico** (como Pontomais, Ahgora, Factorial, Secullum e Kairos).

A finalidade do Punch é permitir que o usuário bata o ponto diretamente pelo Mr-tick e realize a **conferência automática de jornada** — comparando o saldo de horas trabalhadas do dia com o total de horas alocadas em tarefas e projetos.

---

## 🎯 Principais Recursos

- **Batida de Ponto Rápida**: Botão de 1 clique no menu de contexto ou atalho de teclado para registrar Entrada, Intervalo e Saída.
- **Auditoria de Horas (Jornada vs. Apontamentos)**: Exibe a diferença entre o tempo formal de trabalho e o tempo apontado em tarefas no DataSource, evitando inconsistências ao final do mês.
- **Histórico e Espelho de Ponto**: Visualização do extrato diário de batidas diretamente no Mr-tick.

### 2. `src/index.ts`
```typescript
import type { IAddon, AddonContext } from '@mr-tick/sdk'

export interface PunchRecordDTO {
  id: string
  timestamp: Date
  type: 'in' | 'out' | 'break_start' | 'break_end'
  source: string
}

export default class PontoCorporativoAddon implements IAddon {
  private context: AddonContext | null = null

  public activate(context: AddonContext): void {
    this.context = context

    context.settings.register([
      {
        id: 'general',
        label: 'Geral',
        groups: [
          {
            id: 'ponto_auth',
            label: 'Configurações de Acesso',
            fields: [
              {
                id: 'pontoApiUrl',
                label: 'URL da API de Ponto',
                type: 'text',
                scope: 'configuration',
                required: true,
                description: 'Endereço da API do sistema de ponto da empresa.',
              },
              {
                id: 'pontoToken',
                label: 'Token de Acesso / Chave do Colaborador',
                type: 'password',
                scope: 'credential',
                required: true,
              },
            ],
          },
        ],
      },
    ])

    console.log('[Punch] Addon de Ponto ativado!')
  }

  public deactivate(): void {
    this.context = null
  }

  // Executa uma nova batida de ponto
  public async registerPunch(
    type: 'in' | 'out' | 'break_start' | 'break_end',
  ): Promise<PunchRecordDTO> {
    const apiUrl = await this.context?.storage.get('pontoApiUrl')
    const token = await this.context?.storage.get('pontoToken')

    const response = await fetch(`${apiUrl}/punches`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${token}`,
      },
      body: JSON.stringify({
        type,
        timestamp: new Date().toISOString(),
      }),
    })

    if (!response.ok) {
      throw new Error(
        `Falha ao registrar batida de ponto: HTTP ${response.status}`,
      )
    }

    const data: { id: string; timestamp: string } = await response.json()

    await this.context?.notifications.success(
      `Batida de ponto (${type}) realizada com sucesso!`,
      'Ponto Registrado',
    )

    return {
      id: data.id,
      timestamp: new Date(data.timestamp),
      type,
      source: 'Mr-tick Desktop',
    }
  }
}
```
