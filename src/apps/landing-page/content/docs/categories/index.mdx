## Available Categories

Browse these sections to learn how to implement each type of extension:

- **[📦 DataSources](/docs/categories/datasources)**: Connect to project management platforms (Jira, Redmine, YouTrack), fetch tasks, and submit time entries.
- **[👁️ Observers & Watchers](/docs/categories/watchers)**: Monitor voice calls, Git commits, IDEs, and idle time in the background to generate one-click time suggestions.
- **[📅 Calendars](/docs/categories/calendars)**: Integrate corporate calendars (Google Calendar, Outlook) to turn meetings into time entries.
- **[🎨 Themes](/docs/categories/themes)**: Customize visual themes with CSS tokens for light and dark modes.
- **[⏱️ Punch](/docs/categories/punch)**: Integrate corporate time clocks and audit daily working hours.
