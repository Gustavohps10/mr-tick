O SDK é um conjunto de ferramentas para criar extensões para o Mr. Tick. Com ele, você pode adicionar integrações, ações e personalizações visuais sem precisar alterar o aplicativo.

Essas extensões são chamadas de **addons**. Cada addon oferece uma funcionalidade que o usuário pode instalar conforme sua necessidade, como conectar uma ferramenta de trabalho ou sugerir apontamentos após uma reunião.

## O que você pode estender?

- **Conectar ferramentas de trabalho:** trazer tarefas para o Mr. Tick e enviar apontamentos para o sistema de origem. O addon do Redmine é um exemplo.
- **Criar observadores de atividade:** detectar chamadas de voz ou outras atividades e oferecer sugestões de apontamento, como faz o addon do Discord.
- **Adicionar ações e atalhos:** registrar comandos e itens nos menus laterais ou na barra do timer.
- **Personalizar a interface:** criar temas com suas próprias cores e identidade visual.
- **Usar o timer e os apontamentos:** consultar informações, controlar o timer e criar registros ou sugestões locais.

Um addon pode combinar essas funcionalidades. Integrações de calendário ou ponto podem usar os mesmos pontos de extensão, mas o SDK não inclui uma integração pronta ou uma tela específica para cada serviço externo.

## Como funciona?

Seu addon descreve as funcionalidades que oferece e as registra no Mr. Tick. O aplicativo disponibiliza suas funções suportadas e cuida da ligação com a interface. Você implementa o comportamento específico da sua integração.

O SDK também fornece os contratos para conexão de contas, configurações, armazenamento privado e eventos do aplicativo. Eles ajudam cada addon a usar a conta e o workspace corretos.

Esta documentação descreve o contrato da próxima linha do SDK, 0.11. Para usar `auth`, aguarde a publicação dessa versão e o desktop compatível.

## Por onde começar

1. Siga o [guia rápido](/pt-br/docs/quickstart) para criar, compilar e empacotar um addon pequeno.
2. Escolha suas [capabilities](/pt-br/docs/capabilities), que descrevem as funcionalidades oferecidas.
3. Se ele conectar uma conta externa, leia [autenticação](/pt-br/docs/capabilities/auth) e [OAuth PKCE](/pt-br/docs/apis/oauth-pkce).
4. Use [configurações, armazenamento privado e eventos](/pt-br/docs/apis/vault-and-events) conforme necessário.
5. Para integrar tarefas e apontamentos, consulte [datasources](/pt-br/docs/capabilities/datasources) e [sincronização](/pt-br/docs/sync-engine).

## Desenvolvendo com o SDK

Instale o pacote publicado `@mr-tick/sdk` no seu projeto. Você não precisa dos pacotes privados usados para construir o Mr. Tick. Os guias apresentam os tipos e métodos quando eles forem necessários para a implementação.

Addons executam código dentro do aplicativo. Instale extensões de autores em quem você confia: o SDK não isola esse código para impedir ações maliciosas. Salvar um apontamento localmente também não significa que um serviço externo já o aceitou.
